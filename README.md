# 🧠 CORVUS 2.0
### Agente Inteligente da Ordem Masayoshi

**Corvus 2.0** é um agente inteligente integrado a automações e banco de dados, desenvolvido para atuar como assistente digital oficial da comunidade **Masayoshi (MSY)**.

O sistema centraliza conhecimento interno, responde dúvidas, auxilia membros em tarefas e interage com automações externas.

Este projeto demonstra habilidades em **integração de IA, automação de processos, front-end moderno e backend serverless.**

🔗 **Demo:**  
https://t4msy.github.io/Corvus-2.0/

---

# 📌 Visão Geral

O Corvus funciona como um **chatbot inteligente conectado a fluxos de automação**, permitindo:

- Responder dúvidas dos membros da organização
- Gerar textos, ideias e conteúdos
- Auxiliar cargos internos da ordem
- Integrar dados estruturados via automação
- Registrar informações enviadas pelos usuários

Ele atua como um **hub de conhecimento e produtividade.**

# 🚀 Funcionalidades

## 🔐 Autenticação de usuários
Sistema de login integrado ao **Supabase Auth**.

## 💬 Interface de chat inteligente
Os usuários podem interagir com o agente Corvus para:

- tirar dúvidas
- gerar conteúdo
- obter informações da organização

## 🔄 Integração com automações
Mensagens e formulários podem ativar **fluxos automatizados via n8n**.

## 📝 Renderização avançada
O sistema suporta **Markdown**, permitindo respostas estruturadas.

## 📱 Interface otimizada
- UI moderna
- Responsiva
- Experiência similar a aplicativos de chat
